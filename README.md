## 📖 Project Overview
This project is based on the famous **Iris Flower Dataset**. The main objective is to build a Machine Learning model that can classify Iris flowers into different species based on their sepal and petal measurements.

The dataset contains three different flower species:
* 🌼 **Iris Setosa**
* 🌺 **Iris Versicolor**
* 🌷 **Iris Virginica**

Data Science techniques were used to train the model and predict the flower species with high accuracy.

## 🛠️ Technologies Used
* **Python** 🐍
* **Pandas** & **NumPy** 📊 (Data Manipulation)
* **Matplotlib** & **Seaborn** 📈 (Data Visualization)
* **Scikit-learn** 🤖 (Machine Learning)
* **Google Colab** 📓

## 📊 Dataset Information
The dataset contains the following features:
* `Sepal Length`
* `Sepal Width`
* `Petal Length`
* `Petal Width`
* `Species` (Target)

## 🧠 Machine Learning Model
* **Random Forest Classifier** was used for training and prediction.
* The model achieved very high accuracy in classifying the flower species.
